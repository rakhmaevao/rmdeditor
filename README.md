# RMdEditor

Прототип Live Preview для VS Code: редактирование Markdown в одной вкладке, без бокового предпросмотра. Только светлая тема: исходные цвета Obsidian Nord Light без коррекции контраста, белый фон и цветные заголовки. Размер текста — 18px. Mermaid также использует светлую палитру независимо от темы VS Code.

## Установка

Установите собранный `rmdeditor-<версия>.vsix` через команду **Extensions: Install from VSIX**. Откройте `.md`, выполните **Reopen Editor With… → RMdEditor**. При желании выберите **Configure default editor** в этом меню.

На активной строке видны маркеры Markdown; на остальных скрываются маркеры заголовков, выделений и кода. Разделители `---`, `***` и `___` вне активной строки отображаются горизонтальной линией; разделители YAML frontmatter остаются текстом. Слева отображаются номера строк исходного текста. Mermaid в fenced-блоках отображается внутри документа. Нажмите диаграмму для редактирования; переведите курсор за пределы блока для рендера. Сохранение — обычное Ctrl+S. Есть история редактирования Ctrl+Z/Ctrl+Shift+Z.

Ссылки вне активной строки открываются нажатием: Markdown-ссылки, а также автоматические — голые `https://…`, `www.…` и `<…>`. Веб-ссылки открываются в браузере, относительные пути — в VS Code.

Поиск работает как в обычном текстовом редакторе: Ctrl+F открывает плавающую панель с подсветкой всех совпадений и счётчиком «n из m», Enter и Shift+Enter (или F3) переходят между совпадениями, Esc закрывает панель. Ctrl+H открывает ту же панель с полем замены («Заменить», «Заменить всё»). Поддерживаются учёт регистра (Aa), целые слова (ab) и регулярные выражения (.*); некорректное выражение подсвечивается красным. Ctrl+D добавляет следующее совпадение к выделению, Ctrl+Shift+L выделяет все совпадения. Совпадения внутри отображаемых таблиц и ссылок становятся видны при переходе к ним: блок раскрывается в исходный Markdown.

Markdown-изображения отображаются вне активной строки и уменьшаются до ширины редактора. Относительные пути, например `figures/image.png`, считаются от папки Markdown-файла; доступны изображения из этой папки и открытого рабочего пространства, HTTP(S) и `data:image/` URL. Поддерживаются также изображения со ссылочными определениями (reference-style). Нажмите картинку или сообщение об ошибке загрузки, чтобы редактировать исходный Markdown.

Одиночные переносы строк отображаются как переносы строк, как в Obsidian: строки абзаца никогда не склеиваются в одну визуальную строку. Текст и таблицы занимают доступную ширину редактора, столбцы таблиц имеют одинаковую ширину.

Абзац, первая строка которого начинается с `TODO:`, `ТУДУ:` (оранжевый) или `FIXME:` (розовый), выделяется цветной полосой с белым текстом и скруглёнными углами на всех строках абзаца. Маркер внутри обычного абзаца, элемента списка, цитаты или заголовка подсвечивается от ключевого слова до конца предложения — до первой точки (включительно) или закрывающей скобки. Совпадения точные и чувствительные к регистру; frontmatter и fenced-блоки кода не подсвечиваются.

## Разработка

`npm ci`, `npm run check`, `npm run build`, затем F5 в VS Code. Упаковка: `npm run package`.

Проверка Live Preview в браузере: `npx playwright install chromium`, затем `npm test`. Для установленного Chrome можно вместо загрузки Chromium выполнить `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/google-chrome npm test`. Тесты проверяют оформление после фонового разбора длинного документа и внешнего обновления текста.

## Границы прототипа

- Это Live Preview, а не полный визуальный редактор: списки задач и wikilinks пока остаются текстом Markdown. Таблицы отображаются визуально, кнопка «Редактировать» открывает их исходный Markdown. Форматирование и изображения внутри ячеек пока показываются текстом.
- Тема фиксированная светлая; синхронизация темы Obsidian отсутствует.
- Mermaid выполняется локально с securityLevel strict; внешние ресурсы webview разрешены только для изображений.
- Исходный Markdown не проходит преобразование через HTML: YAML и неизвестные конструкции сохраняются.
- Одновременное редактирование того же файла извне может заменить локальное несинхронизированное изменение; избегайте параллельной правки одного файла.
- Сборка, типы и обновление Live Preview проверяются автоматически. Интерактивное поведение в Extension Host требует ручной проверки.

Архитектура использует [VS Code Custom Text Editor API](https://code.visualstudio.com/api/extension-guides/custom-editors), CodeMirror 6 и Mermaid.

Блоки кода отображаются исходным текстом с номерами строк и видимыми маркерами fenced-блока (окрашены в синий); Mermaid продолжает рендериться диаграммой. Содержимое подсвечивается по указанному языку (полный набор highlight.js, включая Julia, R, MATLAB и другие). Неизвестный язык отображается обычным текстом; правки внутри блока выполняются как в обычном тексте.
